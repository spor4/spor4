## Koios: Agency

- 🏛️ **[Koios Hub](https://koios-lab.ai)**: client platform with per-client portals for offers + e-sign, contracts, wikis, moodboards and approval queues
- 🧠 **[Company Brain](https://www.koios-lab.ai/toolkit/knowledge-base)**: agent-maintained knowledge bases per client, fed by an intake pipeline
- 📒 **Accountant Agent**: German bookkeeping automation (OCR → VAT → sevDesk), grown into a full ops dashboard
